Random Password Generator

A simple Python application that generates secure random passwords based on user-defined length.

Features

- Generate passwords of custom length
- Includes letters, numbers, and special characters
- Easy-to-use command-line interface

Technologies Used

- Python 3
- random module
- string module

How to Run

python password_generator.py

Sample Output

Enter password length: 10

Generated Password: A@7k#P2m!X
