# Expense Tracker

## Description
Expense Tracker is a simple Python application that helps users record their expenses and calculate the total amount spent.
It demonstrates the use of loops, user input, variables and mathematical operations in python.


## Features
- Add multiple expense amounts
- Calculate total expenses automatically
- User-friendly console interface
- Display final spending summary
